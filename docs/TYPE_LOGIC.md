# 类型逻辑说明

## 内容类型分类

### 1. 文本 (text)
- **触发条件**: 默认类型，不匹配其他任何类型
- **单击操作**: 粘贴到输入框
- **悬浮按钮**: 仅复制
- **图标**: 📋

### 2. 代码 (code)
- **触发条件**:
  - 包含编程关键字: `def`, `class`, `function`, `const`, `import`, `from`, `return`
  - 包含代码符号: `{}`, `[]`, `()`, `;`, `=>`
  - 包含注释: `//`, `#`, `/*`
  - 包含函数调用: `print(`, `console.log`
- **单击操作**: 粘贴到输入框
- **悬浮按钮**: 打开源文件、仅复制
- **图标**: `</>`

### 3. 链接 (url)
- **触发条件**: 以 `http://` 或 `https://` 开头
- **单击操作**: 粘贴 URL
- **悬浮按钮**: 打开浏览器、仅复制
- **图标**: 🔗

### 4. 图片 (image)
- **触发条件**:
  - 本地路径: `C:\path\to\image.png`
  - 网络URL: `https://example.com/image.jpg`
  - 支持格式: `.png`, `.jpg`, `.jpeg`, `.gif`, `.bmp`, `.webp`, `.svg`, `.ico`, `.tiff`
- **单击操作**: 打开图片
- **悬浮按钮**: 打开文件夹、仅复制
- **图标**: 🖼️

### 5. 文件 (file)
- **触发条件**:
  - 本地路径且有扩展名: `C:\path\to\document.pdf`
  - 不是图片类型
- **单击操作**: 打开文件
- **悬浮按钮**: 打开文件夹、复制路径
- **图标**: 📄

### 6. 路径 (path)
- **触发条件**:
  - 本地路径但没有扩展名: `C:\Users\Documents`
  - 或是目录路径
- **单击操作**: 打开文件夹
- **悬浮按钮**: 复制路径
- **图标**: 📁

### 7. 项目 (project)
- **触发条件**: 从 IDE 窗口标题自动识别
  - VS Code: `file.py — project-name - Visual Studio Code`
  - PyCharm: `project-name - PyCharm`
  - 终端: `path - Terminal`
- **单击操作**: 用对应 IDE 打开
- **悬浮按钮**: 打开文件夹、复制名称
- **图标**: 📂

### 8. 应用 (tool)
- **触发条件**: 从窗口进程名识别
- **单击操作**: 复制应用路径
- **悬浮按钮**: 启动应用
- **图标**: 💻

## 排序逻辑

1. **按使用次数排序**: 复制/使用次数多的排在前面
2. **按时间排序**: 同次数的按最近使用时间排序

## 搜索逻辑

- 搜索范围: 内容预览、应用名、项目名
- 不区分大小写
- 实时搜索（80ms 防抖）

## 权限控制

| 权限 | 控制的操作 |
|------|-----------|
| 打开文件 | 文件、图片、项目、代码源文件 |
| 打开链接 | URL 在浏览器打开 |
| 启动应用 | 应用直接启动 |
| 打开文件夹 | 文件夹跳转 |
| 自动粘贴 | 单击后自动 Ctrl+V |
